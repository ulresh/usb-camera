# USB камера

Android-приложение (`com.github.ulresh.usb_camera`, minSdk 27) для проверки
настроек видеокамеры и микрофона, в том числе подключённых по USB.

## Возможности

- Показ видео с камеры на экране.
- Выбор камеры (встроенные и внешние USB-камеры; список обновляется при
  подключении и отключении).
- Параметры камеры: кодировка (H.264, H.265 при наличии аппаратного кодера),
  разрешение, частота кадров, битрейт.
- Микрофон: частота дискретизации, чувствительность (программное усиление
  от −12 до +30 дБ, меняется на лету), индикатор уровня.
- Включение и выключение трансляции видео и звука в сеть независимо друг от
  друга. Поток MPEG-TS (H.264/H.265 + AAC) отдаётся по HTTP:
  `http://<ip устройства>:<порт>/` (порт по умолчанию 8080). Открывается в
  VLC, ffplay и т. п.
- Настройки сохраняются между запусками.

Приложение не использует сторонних библиотек — только Android framework
(Camera2, MediaCodec, AudioRecord).

## Ограничения

- Трансляция работает, пока приложение на экране (фонового режима нет).
- Поток передаётся в ориентации сенсора; для встроенных камер с повёрнутым
  сенсором изображение в потоке может быть повёрнуто.

## Сборка

```
gradle assembleDebug      # app/build/outputs/apk/debug/app-debug.apk
gradle assembleRelease    # требуется release.keystore в корне проекта
```

Release подписывается ключом `release.keystore` (алиас `usbcamera`), который
в репозиторий не входит; создать его можно командой `keytool -genkeypair`
(параметры — в `app/build.gradle.kts`).
